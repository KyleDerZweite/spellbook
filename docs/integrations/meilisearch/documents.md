This document describes the current Spellbook document shape and ingestion rules.

## Primary Key

Both current Spellbook indexes use `id` as the primary key.

In Spellbook, `id` is the Scryfall card printing ID.

## Current Ingestion Rules

- tokens and other non-game layouts are skipped
- documents without `id` or `oracle_id` are skipped
- documents are sorted by `released_at` descending before upload
- the same transformed document set is uploaded to both `cards_distinct` and `cards_all`
- each document includes `normalized_name` for exact import matching
- `printed_name` stores the localized name, using joined face names when no top-level printed name exists
- `name` retains the canonical Scryfall name; localized search does not change exact import matching
- multi-face oracle text combines face text for search

Release-date insertion order does not guarantee the printing selected by distinct search. MeiliSearch ranking and the query determine the representative result.

## Import fields

`normalized_name` is generated by lowercasing, trimming, collapsing whitespace, removing punctuation that should not affect exact matching, and normalizing split names to the `front // back` shape.

Import resolution uses:

- `cards_all` for exact set plus collector-number lines
- `cards_distinct` for name-only lines
- exact `normalized_name` matches in both paths
